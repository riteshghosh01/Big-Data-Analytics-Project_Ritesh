# Big-Data-Analytics-Project
This project demonstrates practical implementation of Big Data technologies within the Hadoop ecosystem using Apache Sqoop, Apache Pig, and Apache Hive. It covers data import/export operations between MySQL and HDFS, data processing using Pig Latin scripts, and data warehousing techniques with Hive including internal/external tables and static/dynamic partitioning. The project provides hands-on experience with distributed data processing, Hadoop storage management, and analytical operations on large datasets.
